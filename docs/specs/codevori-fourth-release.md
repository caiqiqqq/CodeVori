# CodeVori 第四个安装版本

## 产品规则与交付范围

- 新版本为 `1.0.3`，根 `package.json` 是版本唯一来源。
- 提交并推送已完成的 ACP 上下文压缩、结构化错误提示及共享时间轴贴底定位
  spec、实现和测试到 `private/main`。安装包与生成的 sourcemap 不入库。
- 从推送后核对一致的固定提交创建独立构建 worktree，重新构建桌面、内置
  Agent 和 Computer Use 插件，交付 macOS arm64 DMG、ZIP、校验和与构建来源。
- 保留此前版本产物、开发进程产物和真实用户数据。复用免登录启动、品牌、
  官方更新禁用规则。只构建本地安装包，不发布远端 Release。
- 沿用本地 ad-hoc 签名，验证完整性；没有 Apple 公证时如实标明。

## 所有者与交付顺序

```text
根版本 / 已验证源码 → commit → push private/main → 核对精确 commit
                   → 独立 worktree 重新编译 → 打包与运行时资源校验
                   → 临时用户目录启动检查 → DMG / ZIP / SHA-256 / 来源记录
```

版本由根 manifest 持有，现有 build metadata 关联提交及构建时间。
构建不引入新的会话状态、Host 或远程恢复路径。启动测试使用临时数据目录，
不读取真实会话，也不请求模型。远端提交一致及最终安装包验证通过后才宣告完成。

## 验收

1. `private/main` 等于本地交付提交，无关生成文件保持未跟踪。
2. 相关回归测试、类型、Lint、架构及改动格式检查通过，记录已有警告。
3. 安装包版本 `1.0.3`，元数据指向已推送提交；内置 Agent、Computer Use
   插件、平台资源及运行时依赖闭包校验通过。
4. 临时数据目录实际启动免登录主窗口，官方更新禁用，签名完整性通过。
5. DMG / ZIP 完整性检查通过，交付产物及 SHA-256，并记录公证状态。
