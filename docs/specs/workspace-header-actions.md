# 工作区顶部工具栏

## 产品规则与边界

- 主工作区的 API、ACP 和新对话顶部，以及待办任务的右侧对话顶部，不显示问号帮助按钮，也不保留占位。
- 原有 Finder/编辑器、分享、终端、侧栏和桌面窗控继续遵循各自的显示与交互规则。
- 设置页现有帮助入口和桌面原生帮助菜单保留，共享帮助组件仍由这些入口使用。
- Web 隐藏全局侧栏、进入待办任务等非聊天主视图时，主会话框架顶部为全局悬浮导航保留独立的 56px 区域，与 `DesktopTopOverlay` 的高度一致。任务标题、状态、任务操作及来源链接排在该区域之后，不能与侧栏开关、前进/后退或新建按钮重叠。侧栏可见时导航位于侧栏内，桌面已有拖拽栏及聊天页现有标题栏留白不再重复预留。
- 全局导航只有一个侧栏展开/收起入口，视觉上也只占一个按钮位。macOS 移除 V/Logo 图标及其占位，保留侧栏图标按钮；默认、鼠标悬停及键盘聚焦均只显示侧栏图标。Windows、Linux 和 Web 同样使用单一侧栏图标按钮。展开/收起图标跟随现有侧栏显隐，原快捷键、导航、新建及窗控规则不变。

## 所有者与接口

- `WorkspaceHeaderActionSection` 唯一负责工作区顶部工具组的渲染；`WorkspaceHeader` 和 `WorkTaskConversationPane` 继续复用它。
- 删除工作区已无意义的 `hideHelpMenu` 参数，不增加开关、持久化字段或新的状态所有者。
- 这次仅移除入口，不修改平台命令、帮助菜单内容、会话、草稿、任务执行和远程事件链路。
- Web 导航留白由 `WorkspaceShellLayout` 统一管理，复用现有 `isDesktop`、侧栏显隐和主视图路由，不增加状态或在任务标题栏中猜测全局导航宽度；导航与任务操作仍调用原回调。
- `DesktopTopOverlay` 仅投影传入的侧栏显隐并调用原 `onToggleSidebar`，不持有第二份显隐状态。顶部导航不接收或渲染 Logo，不保留品牌占位；应用其他位置的品牌展示不变。

## 验收与验证

1. 普通对话及 API/ACP 任务对话顶部没有帮助按钮，其余工具仍可点击，切换工具保留原会话与草稿。
2. 宽屏与 320px 窄屏、深浅主题下，工具组没有横向溢出或帮助按钮占位。
3. 设置页共用的帮助菜单仍可打开并执行原操作。
4. 复用 `workTaskWorkspaceTools.e2e.mjs` 和 `workTasks.e2e.mjs` 验证工具交互与响应式布局；`productBranding.e2e.mjs` 验证保留的共享帮助菜单。
5. 执行根类型检查、Lint、架构检查和改动文件格式检查。
6. 真实全局导航与真实待办会话标题组合在 320px/390px Web、明暗主题和 API/ACP 任务下，导航按钮与标题、状态、来源链接及任务/工作区操作的矩形没有交叠，任务详情和返回仍可点击，工具切换保留同一会话和草稿；桌面导航位置不变。测试只替换会话业务内容与外部服务，不替换全局导航或任务标题布局。
7. 手机触摸模式下，任务标题旁“返回待办”的中心命中该按钮，不能被全局导航拦截；在上述尺寸、主题及 API/ACP 任务组合中，轻触返回后显示任务列表，再选择原任务仍打开原绑定会话。返回只使用已有导航选择状态，不触发任务、会话或 Agent 写入。
8. macOS 普通/全屏、Windows、Linux、320px/390px Web，中英文及明暗主题下均只有一个可访问侧栏开关；点击、触摸和键盘只调用一次回调并切换实际侧栏显示。默认、悬停、键盘聚焦和侧栏展开/收起时，唯一入口始终显示对应的侧栏图标，不渲染 V/Logo 或额外品牌占位；后退按钮紧邻此唯一入口。原前进、后退、新建回调继续可用。

## 手机选择会话后的页面位置

- `WorkbenchConversationTabs` 只调整自身 tablist 的水平滚动位置，使活动标签可见；禁止使用会滚动外层祖先的 `scrollIntoView`。方向键、Home/End 聚焦使用 `preventScroll`，继续通过原 pane 激活回调切换会话。
- WorkspaceShellLayout 在窄屏 Web 下允许主内容区随侧栏后的剩余宽度收缩，侧栏展开时不再用主内容 320px 最小宽度撑宽工作区；桌面及宽屏 Web 的既有最小宽度不变。侧栏显隐、宽度和自动收起仍由原 owner 管理，不新增 drawer 状态。
- 验收：320/394px 手机，侧栏展开/收起、首次打开/再次选择、多个标签切换及键盘导航时，工作区 scrollLeft 始终为 0，侧栏按钮完整且中心可点击。标签自身仍能滚动到活动标签。明暗主题和桌面宽屏回归均覆盖。
- 2026-10-15 验证：`workbenchTabScroll.e2e.mjs` 使用真实 WorkspaceShellLayout、DesktopTopOverlay 和 WorkbenchConversationTabs，替换侧栏列表、会话业务内容和标题插槽，保留真实侧栏容器及开关；修复前窄屏侧栏与主内容总宽度溢出断言失败。修复后 320/394px Web、1280px macOS、明暗主题通过首次打开、tablist 内滚动、Home/End/方向键焦点、侧栏中心命中及触摸开关检查，外壳无横向滚动、导航无裁切。根类型检查通过，Lint 0 错误、74 条警告，架构 current/baseline/new 均为 0。使用 Chromium 隔离测试，未更新安装包或验证 iPhone Safari 实机。
