# 设置项的窄屏布局

## 问题与规则

常规设置复用 `SettingsRow`，其默认布局一直预留 192px 控件列。手机还需容纳侧栏及卡片边距，剩余文字列会被挤到几字宽，终端 Profile 和字体说明因此异常拉长。

- 根据设置行实际可用宽度响应布局，不能只根据视口判断；桌面侧栏和分栏同样会缩小内容区。
- 默认、wide、balanced 行在内容宽度不足 32rem 时上下排列：标题和说明占满一行，控件位于其下并靠左。足够宽时恢复原有两列宽度和右对齐。
- compact 行保留文本与小型控件同行；文本允许长词换行，控件不得把行撑出卡片。
- 控件组可以换行，固定宽度输入/选择器不超过可用列宽。外部 detail 仍按原有顺序出现在行下方，不改变保存、禁用或错误语义。
- 复用现有字体、主题和组件；不修改全局字号，不改变设置值或状态所有者。

## 所有者及验收

`SettingsRow` 只拥有布局，设置值、保存回调和服务写入路径仍归原页面及控件。布局不新增持久化状态或平台分支。

真实 SettingsPage 在 320/375/390/768/1280px、中英文及明暗主题下验证：终端 Profile 和字体说明保持合理宽度，卡片及控件不横向溢出；开关可点，字体输入与保存仍有效；桌面宽行维持两列。另用宽视口内的窄容器验证响应依据是可用空间。既有局域网设置入口 E2E 保持通过。截图核对文字、控件间距和滚动可达性；浏览器模拟不能视为 iPhone 实机验收。

## 快捷键列表（issue #177）

固定四列表格在手机内容区仍为操作和作用域保留 152px，命令与键位列被压缩，键帽和编辑按钮越入相邻列。

- `ShortcutSettingsSection` 的实际可用宽度不足 48rem 时，每个命令上下展示完整命令名、作用域和绑定列表；清空按钮位于标题右侧，键位占满下一行。宽容器保持四列表头和列对齐。
- 命令名、作用域、录制提示及错误允许换行；长组合键和编辑按钮可换行，不能与作用域或清空按钮重叠，也不能被容器裁切。每条绑定仍有独立的替换入口。
- 搜索框与恢复默认操作在窄内容区上下排列，搜索框及按键搜索按钮必须可用。采用现有字体、间距及主题 token，不缩小文字来容纳表格。
- 仅调整展示布局；`ShortcutSettingsSection` 继续拥有搜索和录制状态，`useSettings` 继续通过现有设置服务保存绑定。保留 Web menu 通道不可编辑规则、冲突提示、清空及恢复默认语义，不新增状态、服务、协议或持久化路径。
- 验收：真实 `SettingsPage` 在 320/375/390/768/1280px、中英文及明暗主题验证命令完整、键帽/编辑/作用域互不遮挡、所有控件在内容范围内；宽视口内窄容器同样切换。覆盖多绑定、长组合键、未分配、录制和冲突提示，验证搜索、清空和替换保存，确认宽屏仍为四列。浏览器模拟与手机实机验收分别记录。
