# 设置项的窄屏布局

## 问题与规则

常规设置复用 `SettingsRow`，其默认布局一直预留 192px 控件列。手机还需容纳侧栏及卡片边距，剩余文字列会被挤到几字宽，终端 Profile 和字体说明因此异常拉长。

- 根据设置行实际可用宽度响应布局，不能只根据视口判断；桌面侧栏和分栏同样会缩小内容区。
- 默认、wide、balanced 行在内容宽度不足 32rem 时上下排列：标题和说明占满一行，控件位于其下并靠左。足够宽时恢复原有两列宽度和右对齐。
- compact 行保留文本与小型控件同行；文本允许长词换行，控件不得把行撑出卡片。
- 控件组可以换行，固定宽度输入/选择器不超过可用列宽。外部 detail 仍按原有顺序出现在行下方，不改变保存、禁用或错误语义。
- 复用现有字体、主题和组件；不修改全局字号，不改变设置值或状态所有者。

## 所有者及验收

`SettingsRow` 只拥有布局，设置值、保存回调和服务写入路径仍归原页面及控件。布局不新增持久化状态或平台分支。

真实 SettingsPage 在 320/375/390/768/1280px、中英文及明暗主题下验证：终端 Profile 和字体说明保持合理宽度，卡片及控件不横向溢出；开关可点，字体输入与保存仍有效；桌面宽行维持两列。另用宽视口内的窄容器验证响应依据是可用空间。既有局域网设置入口 E2E 保持通过。截图核对文字、控件间距和滚动可达性；浏览器模拟不能视为 iPhone 实机验收。
